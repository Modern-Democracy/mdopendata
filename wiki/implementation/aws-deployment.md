This page documents the repeatable AWS deployment and synchronization workflow for the mdopendata PostGIS database and web application.

# AWS Deployment

## Deployment Shape

The first AWS deployment uses one Amazon Linux 2023 EC2 instance running Docker Compose.

Repository artifacts:

- Infrastructure template: `infra/aws/mdopendata-ec2.yml`.
- AWS Compose file: `docker-compose.aws.yml`.
- Application deploy script: `scripts/aws-deploy.ps1`.
- Database synchronization script: `scripts/aws-sync-db.ps1`.

The deployed host exposes only the web application on port `80` and SSH on port `22`. PostGIS is private to the Docker network on the EC2 instance.

## Local Prerequisites

Install and configure:

- AWS CLI with credentials for the target account and region.
- An EC2 key pair in the target AWS region.
- OpenSSH client with access to the private key file.
- Docker locally, with `mdopendata-postgis` running when synchronizing the database.

Set `AWS_REGION` or pass `-Region` to the scripts.

## First Deployment

Run from the repository root:

```powershell
.\scripts\aws-deploy.ps1 `
  -StackName mdopendata `
  -Region us-east-1 `
  -AwsProfile mdopendata `
  -KeyName your-ec2-keypair-name `
  -SshKeyPath C:\path\to\your-key.pem `
  -SshLocation 203.0.113.10/32 `
  -PgPassword "replace-with-a-strong-password"
```

If the AWS account has no default VPC, pass `-VpcId` and `-SubnetId` for a public subnet.

The script:

1. Deploys the CloudFormation stack.
2. Packages the repository, excluding local database volumes, virtual environments, temporary files, and node modules.
3. Uploads the package to the EC2 instance.
4. Writes the remote `.env`.
5. Rebuilds and starts `docker-compose.aws.yml`.
6. Verifies that PostGIS responds.

Use a narrow `-SshLocation` CIDR rather than `0.0.0.0/0` when possible.

## Application Updates

To redeploy the latest repository files without recreating AWS infrastructure:

```powershell
.\scripts\aws-deploy.ps1 `
  -StackName mdopendata `
  -Region us-east-1 `
  -AwsProfile mdopendata `
  -KeyName your-ec2-keypair-name `
  -SshKeyPath C:\path\to\your-key.pem `
  -PgPassword "replace-with-a-strong-password" `
  -SkipInfrastructure
```

Each deploy creates a timestamped release under `/opt/mdopendata/releases` and updates `/opt/mdopendata/current` to point at the newest release.

## Database Synchronization

To replace the AWS database with the current local database:

```powershell
.\scripts\aws-sync-db.ps1 `
  -StackName mdopendata `
  -Region us-east-1 `
  -AwsProfile mdopendata `
  -SshKeyPath C:\path\to\your-key.pem
```

The script:

1. Runs `pg_dump -Fc` inside the local `mdopendata-postgis` container.
2. Uploads the dump to the EC2 instance.
3. Backs up the current AWS database to `/opt/mdopendata/shared/backups`.
4. Drops and recreates the AWS database.
5. Restores the uploaded dump with `pg_restore`.
6. Restarts the web service.

Use `-NoBackup` only when an AWS-side pre-sync backup is explicitly not needed.

## Verification

After deployment or synchronization:

```powershell
aws cloudformation describe-stacks `
  --region us-east-1 `
  --stack-name mdopendata `
  --query "Stacks[0].Outputs"
```

Open the `WebUrl` output in a browser.

Remote service checks:

```powershell
ssh -i C:\path\to\your-key.pem ec2-user@PUBLIC_IP "cd /opt/mdopendata/current && docker compose -f docker-compose.aws.yml --env-file .env ps"
```

Remote logs:

```powershell
ssh -i C:\path\to\your-key.pem ec2-user@PUBLIC_IP "cd /opt/mdopendata/current && docker compose -f docker-compose.aws.yml --env-file .env logs --tail=100 web"
```

## Operational Notes

The EC2 root volume stores the Docker named volume for PostGIS. Increase `-VolumeSizeGiB` before the first deployment if large spatial layers or database dumps are expected.

The process is not a high-availability production architecture. It is a repeatable single-host deployment that matches the current repository runtime and can be replaced later by RDS plus ECS or another managed topology.

The remote `.env` is generated by `scripts/aws-deploy.ps1` and should not be committed.
